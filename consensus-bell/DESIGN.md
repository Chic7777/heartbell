# Consensus Bell UI contract

## 1. Intent
An intimate consumer app. Emotion precedes action; proofs are disclosed on request. Preserve the existing Kombai design and user-provided 20-screen specification.

## 2. Color
Cream #FFF9F7, rose #E98F93, ink #171717, confirmed #4ECF8B. White surfaces. Ink opacity supplies secondary text and hairlines. Warm amber #F2A65A / #B8732F is reserved for pending. Readable green #2E9E63. Destructive rose #C0646A. Rose-gold #C98877 and blush #E7B7A8 describe ring material.

## 3. Typography
Noto Serif SC / Georgia for emotional headings and vows; Inter / PingFang SC / system-ui for controls. Scale: 11, 12, 14, 16, 18, 22, 28, 32, 48. Body line-height 1.65, heading 1.2. Avoid clipped text and allow long user content to wrap.

## 4. Space and depth
4px base, 8/12/16/20/24/32/40/48 spacing. Card radii 20/24/28; pill buttons. Card shadow: 0 1px 2px rgba(23,23,23,.03), 0 8px 24px rgba(23,23,23,.04). One hero and 2–4 functional areas per primary screen. The live Web App fills the viewport with only its internal header, scrolling content and navigation: no promotional sidebar, phone bezel, outer rounding or device shadow. Center readable content at max 720px (--web-content-max); the radar stage stays max 440px (--web-radar-max) to preserve its reference geometry. Historical ui/ demos retain their original phone-shell presentation. Reuse existing cream, spacing and type tokens.

## 5. Reusable primitives
Header/back action; fixed five-tab navigation; pill primary/secondary/destructive buttons; labeled form rows; interest image tile selected/unselected; state badge pending/confirmed/archived; timeline event; goal card with contribution/progress; bottom dialog with focus containment; proof rows; toast/error live region; ring hero open/waiting/active/ending/archived; blank-state panel. Buttons provide focus, pressed, disabled states. Dialog dismisses on Escape, restores focus. All nondecorative controls have accessible labels.

## 6. Motion
Ring orbit and merge communicate relationship state. Confirmation pulse communicates count change. Transitions use opacity/transform, 180–400ms. Respect prefers-reduced-motion.

## 7. Responsive and accessibility
375/768/1280 viewport targets. Main page owns scrolling; tabs stay outside scrolling content. No horizontal page overflow. Minimum 44px hit area. Forms validate before transition and preserve input on errors. User input is text escaped, never executable HTML. Native date/file/select controls.

Preview must never bypass the backend auth checks or send write requests. No new visual tokens are required.

A missing RPC/deployment is unavailable, never mainnet-verified. Matching is off-chain and does not establish a relationship; invitations still require real on-chain signatures. Current local-App browser QA was authorized and performed on 2026-10-07 without wallet signing or location permission.
