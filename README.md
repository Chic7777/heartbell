# 心动铃铛 · Heartbell

给擦肩而过的心动，一次回应的机会。

Next.js + TypeScript 团队基础框架。包含两用户演示、临时特征、模拟雷达、摇铃、回应、服务器控制的资料揭晓，以及双方确认后可真实上链的情侣日记。无需数据库或钱包即可启动。

## 启动

需要 Node.js 20.9 或更新版本及 npm。

```bash
npm ci
npm run dev
```

打开 http://localhost:3000，从首页分别打开 A、B 窗口，并将窗口调整为约 420px 宽。双方模拟资格声明 → 选择类别并输入特征 → 开启雷达 → A 摇铃 → B 回响 → 双方看到档案 → 写一页情侣日记 → 双方确认 → 各自发起确认交易写入 BOT Chain（或未部署合约时查看链下预览）。

```bash
npm run typecheck
npm run build
npm start
```

重启服务、保持全新演示状态后运行 `npm run verify:demo`，验证资格门槛、资料权限和双方纪念同意。运行 `npm run contracts:compile` 检查 Solidity 并生成本地部署产物（不提交）。

## 已实现与限制

- 手机界面采用三个底部入口：心动雷达、我的回响、情侣日记；顶部钱包按钮点击展开。雷达开启后切换到发现页，收到铃声弹层显示，回响后进入揭晓页。
- 情侣日记支持多页：一方选择节点类型、日期、标题和一句话，另一方确认或婉拒；双方确认后进入上链流程（连接钱包 → 绑定双方钱包 → 部署合约），各自发起一笔确认交易，全部写入后展示纪念碑卡片和交易链接。被婉拒的页面不上链。
- 单身声明首次开启前填写，技术状态放在折叠演示说明里；模拟标识始终保留。页面使用固定手机外框和内部必要滚动，避免所有功能堆成长页。

- A/B 独立演示身份，10 分钟雷达、类别与自定义特征、模拟资格声明、匿名铃声、回应、双方揭晓。
- 两窗口每 1.2 秒同步状态；同一目标雷达轮次限制重复摇铃。
- 长期资料由服务器控制，回响前不会返回给对方。
- 已提供真实浏览器钱包授权及 BOT Chain 网络切换，无扩展时清楚提示。清除连接显示不撤销钱包网站授权。
- 已提供纪念合约源码、编译命令、链上调用模块和情侣日记上链流程。未部署合约时日记仅链下预览，不上链、不生成假交易哈希；上链回报来自前端真实钱包回执，演示服务未独立核验链上数据。钱包绑定是演示记录，不是登录认证。
- ZK 提供接口骨架，真实验证器未配置时拒绝验证；当前资格是模拟声明。尚无真实登录、GPS、真人验证和联系方式交换。
- 内存数据重启后清空，仅适合本地单进程演示，不能作为生产存储或认证机制。
- Supabase 仅预留环境变量，填写后不会自动启用。联调时由后端接入。
