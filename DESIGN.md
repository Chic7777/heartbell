## 1. Intent

## 2. Color

The live Web App fills the viewport with only its internal header, scrolling content and navigation: no promotional sidebar, phone bezel, outer rounding or device shadow. Center readable content at max 720px (--web-content-max); the radar stage stays max 440px (--web-radar-max) to preserve its reference geometry. Historical ui/ demos retain their original phone-shell presentation. Reuse existing cream, spacing and type tokens.

## 6. Motion
Ring orbit and merge communicate relationship state. Confirmation pulse communicates count change. Transitions use opacity/transform, 180–400ms. Respect prefers-reduced-motion.

## 7. Responsive and accessibility

The app enforces the lifecycle state machine: Gateway → Identity → Choose Path → (Radar → Echo → Connect | Direct Bind) → Invitation → Accept → Ceremony → Our Ring → Story/Vow/Bond → Witness → Continue/Archive. Before a Romantic Ring exists (relation status NONE, UNAVAILABLE, INVITED or WAITING) the experience is linear: the five-tab couple navigation (Ring/Story/Vow/Bond/Me) is not rendered, and story, vows, bond, vault, witness, me, privacy, relationship-settings, archived, proofs and history are unreachable — navigating to them (deep link or control) redirects to the path screen with an explicit message. The logged-out entry is the Forever Gateway with the wallet chrome hidden: one visual center, one primary action (Begin Journey), a visitor browsing choice, and a single faint "Secured by BOT Chain" whisper; no wallet address, chain id or hash on the first screen. Only when the on-chain relation becomes ACTIVE, ENDING or ARCHIVED does the persistent Ring/Story/Vow/Bond/Me navigation appear. Radar, Echo and Bell never become tabs. Visitor preview (?preview=1) keeps its declared read-only browsing behavior and is exempt from the redirect so its journey index stays explorable, but it also shows no couple navigation. Server data, chain reads and encryption behavior are unchanged by this contract; it is a client-side presentation gate over the same real state.
